# my_robot

A juiz component written in Python. It was made with `juiz pkg create` of juiz <version>.


## What is inside

| Type | Kind | Arguments (default) | Returns | What it does |
| --- | --- | --- | --- | --- |
| `my_robot_add` | Process | `a: long` (0), `b: long` (0) | `long` | Returns a + b. |

| Path | What it is |
| --- | --- |
| `app/python/my_robot.py` | The Component. Each decorated function is a type |
| `app/app.conf` | The configuration to start juiz with. It is also the entry of the `.juizapp` package |
| `app/juizapp.yaml` | The `.juizapp` manifest (name, version, required juiz and Python versions) |
| `pyproject.toml` | The Python packages this project uses (pyjuiz) |
| `scripts/pack.sh`, `scripts/pack.ps1` | Make `dist/my_robot-<version>.juizapp` |

## Requirements

- juiz <version> with Python support (`juiz --version`). `pip install juiz-cli==<version>` in the venv below is the easiest
- Python 3.10 or later

`pyjuiz` in `pyproject.toml` is pinned to the same version as juiz (`==<version>`).
When you update juiz, update `pyjuiz` to the same version.

## Set up, run and call

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -e .                # installs pyjuiz
juiz -f app/app.conf -d         # start (keep it running)

# in another terminal
juiz process call "http://127.0.0.1:8000/process/my_robot_add0::my_robot_add" '{"a": 1, "b": 2}' -p

scripts/pack.sh                 # make dist/my_robot-0.1.0.juizapp
juiz run dist/my_robot-0.1.0.juizapp
```

On Windows, create the venv with `python -m venv .venv`, activate it with `.venv\Scripts\activate`, and use `scripts\pack.ps1`.
Run `juiz` in a terminal where the venv is activated.

## Versions

The package version is `0.1.0` in both `pyproject.toml` and `app/juizapp.yaml`. When you release a new version, change both.

==== app/python/my_robot.py ====
"""my_robot: a juiz component (juiz docs/spec/pkg.md).

Each decorated function in this file becomes a type of the Component my_robot.
The docstring is the description of the type. Type annotations are required.
"""
from juiz import juiz_process


@juiz_process
def my_robot_add(a: int = 0, b: int = 0) -> int:
    """Returns a + b."""
    return a + b

==== scripts/pack.ps1 ====
# Make dist\my_robot-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts\pack.ps1 [-NoBuild]   (Python has nothing to build; -NoBuild is accepted and ignored)
param([switch]$NoBuild)
$ErrorActionPreference = "Stop"
Set-Location (Join-Path $PSScriptRoot "..")
$stage = Join-Path ([System.IO.Path]::GetTempPath()) ("juiz-pack-" + [System.Guid]::NewGuid())
New-Item -ItemType Directory -Path $stage | Out-Null
try {
    Copy-Item -Recurse -Path "app\*" -Destination $stage
    Get-ChildItem -Path $stage -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force
    foreach ($f in @("LICENSE-MIT", "LICENSE-APACHE")) {
        if (Test-Path $f) { Copy-Item $f $stage }
    }
    New-Item -ItemType Directory -Force -Path dist | Out-Null
    juiz pack $stage -o dist
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
} finally {
    Remove-Item -Recurse -Force $stage
}
==== scripts/pack.sh ====
#!/bin/sh
# Make dist/my_robot-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts/pack.sh [--no-build]   (Python has nothing to build; --no-build is accepted and ignored)
set -eu
cd "$(dirname "$0")/.."
stage=$(mktemp -d)
trap 'rm -rf "$stage"' EXIT
(cd app && tar cf - --exclude=__pycache__ .) | (cd "$stage" && tar xf -)
for f in LICENSE-MIT LICENSE-APACHE; do
  if [ -f "$f" ]; then cp "$f" "$stage/"; fi
done
mkdir -p dist
juiz pack "$stage" -o dist
