==== README.md ====
# my_robot

A juiz component written in Rust. It was made with `juiz pkg create --idl` of juiz <version>,
from the process / container declarations of `idl/robot.jidl`, through the design document `juizdesign.yaml`.


## What is inside

| Type | Kind | Arguments (default) | Returns | What it does |
| --- | --- | --- | --- | --- |
| `turn` | Process | `goal: robot.common.Goal`, `pose: juiz_std.geometry.Pose2D`, `speed: double` (1.0) | `double` | Turns |
| `wheel` | Container | - | - | A wheel |
| `spin` | ContainerProcess | `n: long` (1), `mode: robot.common.Mode` ("FAST") | `long` | - |
| `stop` | ContainerProcess | - | - | - |

| Path | What it is |
| --- | --- |
| `juizdesign.yaml` | The design document: the types of this Component (`juiz pkg design check juizdesign.yaml` checks it) |
| `idl/robot.jidl` | The record and enum types (JIDL) the design document uses (`idl:`) |
| `src/lib.rs` | The Component. Each `#[juiz_component_*]` function is a type, listed in `juiz_component_manifest!`. Write the bodies (`todo!()`) |
| `build.rs` | Generates the Rust types of `idl/robot.jidl` (`juiz_idl`) |
| `app/app.conf` | The configuration to start juiz with. It is also the entry of the `.juizapp` package |
| `app/juizapp.yaml` | The `.juizapp` manifest (name, version, required juiz version) |
| `scripts/dev.sh`, `scripts/dev.ps1` | Build the plugin and put it in `app/plugins/<target>/` |
| `scripts/pack.sh`, `scripts/pack.ps1` | Build in release mode and make `dist/my_robot-<version>.juizapp` |

## Requirements

- juiz <version> (`juiz --version`). Install it with `cargo install juiz_app --version <version>` or `pip install juiz-cli==<version>`
- Rust (cargo)

The juiz crates in `Cargo.toml` are pinned to the same version as juiz (`=<version>`).
When you update juiz, update them to the same version.

## Write, build, run and call

The functions in `src/lib.rs` have the arguments and the return values written in `juizdesign.yaml`, and their bodies are `todo!()`:
calling one before you write it fails. The example calls below use the default values, or a value of the type.

```sh
# write the bodies of the functions (todo!()) in src/lib.rs, then
scripts/dev.sh                  # build and put the plugin in app/plugins/<target>/
juiz -f app/app.conf -d         # start (keep it running)

# in another terminal
juiz process call "http://127.0.0.1:8000/process/turn0::turn" '{"goal":{"mode":"SLOW","pose":{"position":{"x":0.0,"y":0.0},"theta":0.0},"tolerance":0.1},"pose":{"position":{"x":0.0,"y":0.0},"theta":0.0},"speed":1.0}' -p
juiz container-process call "http://127.0.0.1:8000/container_process/spin0::spin:wheel0" '{"mode":"FAST","n":1}' -p
juiz container-process call "http://127.0.0.1:8000/container_process/stop0::stop:wheel0" '{}' -p

scripts/pack.sh                 # make dist/my_robot-0.1.0.juizapp
juiz run dist/my_robot-0.1.0.juizapp
```

On Windows, use `scripts\dev.ps1` and `scripts\pack.ps1` instead of the `.sh` scripts.

## Changing the design

`juiz pkg create -d` does not change a skeleton it has made. When you change `juizdesign.yaml`, change the functions in
`src/lib.rs` and `app/app.conf` to match (`juiz pkg create -d juizdesign.yaml -b rust -o <dir>` writes a new skeleton, to copy from).
`juiz pkg add` adds a type to `src/lib.rs` and `app/app.conf`.

## Versions

The package version is `0.1.0` in both `Cargo.toml` and `app/juizapp.yaml`. When you release a new version, change both.

## Plugins for several OSes in one package

Run `scripts/dev.sh --release` on each OS, collect the `app/plugins/<target>/` directories in one `app/plugins/`, and run `scripts/pack.sh --no-build`.

==== build.rs ====
// Generates the Rust types (record, enum) of the .jidl in OUT_DIR/juiz_idl.rs.
// src/lib.rs includes it. Types of the files imported from `idl/robot.jidl` are generated too.
fn main() {
    juiz_idl::build::configure()
        .extern_path("juiz_std", "::juiz_std_types::juiz_std")
        .compile(&["idl/robot.jidl"])
        .unwrap();
}

/** Turns */

==== scripts/dev.ps1 ====
# Build the plugin and put it in app\plugins\<target>\ (to run app\app.conf during development)
# usage: scripts\dev.ps1 [-Release]
param([switch]$Release)
$ErrorActionPreference = "Stop"
Set-Location (Join-Path $PSScriptRoot "..")
if (-not (Get-Command juiz -ErrorAction SilentlyContinue)) {
    Write-Host "error: juiz is not in PATH. Install juiz <version>:"
    Write-Host "  cargo install juiz_app --version <version>   (or: pip install juiz-cli==<version>)"
    exit 1
}
$target = (juiz pkg target | Out-String).Trim()
if ($Release) {
    $buildProfile = "release"
    cargo build --release
} else {
    $buildProfile = "debug"
    cargo build
}
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
$targetDir = if ($env:CARGO_TARGET_DIR) { $env:CARGO_TARGET_DIR } else { "target" }
$lib = "my_robot.dll"
$dest = Join-Path "app\plugins" $target
New-Item -ItemType Directory -Force -Path $dest | Out-Null
Copy-Item (Join-Path (Join-Path $targetDir $buildProfile) $lib) $dest
Write-Output (Join-Path $dest $lib)
==== scripts/dev.sh ====
#!/bin/sh
# Build the plugin and put it in app/plugins/<target>/ (to run app/app.conf during development)
# usage: scripts/dev.sh [--release]
set -eu
cd "$(dirname "$0")/.."
if ! command -v juiz >/dev/null 2>&1; then
  echo "error: juiz is not in PATH. Install juiz <version>:" >&2
  echo "  cargo install juiz_app --version <version>   (or: pip install juiz-cli==<version>)" >&2
  exit 1
fi
target=$(juiz pkg target)
if [ "${1:-}" = "--release" ]; then
  profile=release
  cargo build --release
else
  profile=debug
  cargo build
fi
case "$target" in
  *apple-darwin) lib=libmy_robot.dylib ;;
  *windows*) lib=my_robot.dll ;;
  *) lib=libmy_robot.so ;;
esac
mkdir -p "app/plugins/$target"
cp "${CARGO_TARGET_DIR:-target}/$profile/$lib" "app/plugins/$target/"
echo "app/plugins/$target/$lib"
==== scripts/pack.ps1 ====
# Make dist\my_robot-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts\pack.ps1 [-NoBuild]
#   -NoBuild: do not build; pack the plugins already in app\plugins\<target>\
param([switch]$NoBuild)
$ErrorActionPreference = "Stop"
Set-Location (Join-Path $PSScriptRoot "..")
if (-not $NoBuild) {
    & (Join-Path $PSScriptRoot "dev.ps1") -Release
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
}
$stage = Join-Path ([System.IO.Path]::GetTempPath()) ("juiz-pack-" + [System.Guid]::NewGuid())
New-Item -ItemType Directory -Path $stage | Out-Null
try {
    Copy-Item -Recurse -Path "app\*" -Destination $stage
    Get-ChildItem -Path $stage -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force
    foreach ($f in @("LICENSE-MIT", "LICENSE-APACHE")) {
        if (Test-Path $f) { Copy-Item $f $stage }
    }
    New-Item -ItemType Directory -Force -Path dist | Out-Null
    juiz pack $stage -o dist
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
} finally {
    Remove-Item -Recurse -Force $stage
}
==== scripts/pack.sh ====
#!/bin/sh
# Make dist/my_robot-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts/pack.sh [--no-build]
#   --no-build: do not build; pack the plugins already in app/plugins/<target>/
#               (to put plugins built on several OSes into one .juizapp, collect them there first)
set -eu
cd "$(dirname "$0")/.."
if [ "${1:-}" != "--no-build" ]; then
  scripts/dev.sh --release
fi
stage=$(mktemp -d)
trap 'rm -rf "$stage"' EXIT
(cd app && tar cf - --exclude=__pycache__ .) | (cd "$stage" && tar xf -)
for f in LICENSE-MIT LICENSE-APACHE; do
  if [ -f "$f" ]; then cp "$f" "$stage/"; fi
done
mkdir -p dist
juiz pack "$stage" -o dist
