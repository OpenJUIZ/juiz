==== README.md ====
# rover

A juiz component written in Python. It was made with `juiz pkg create -d` of juiz <version>,
from the design document `juizdesign.yaml`.


## What is inside

| Type | Kind | Arguments (default) | Returns | What it does |
| --- | --- | --- | --- | --- |
| `rover_stop_command` | Process | - | `rover.types.Velocity` | - |
| `rover_base` | Container | `wheel_base: double` (0.3) | - | - |
| `rover_base_drive` | ContainerProcess | `command: rover.types.Velocity` | `juiz_std.geometry.Pose2D` | - |
| `rover_base_pose` | ContainerProcess (readonly) | - | `juiz_std.geometry.Pose2D` | - |

| Path | What it is |
| --- | --- |
| `juizdesign.yaml` | The design document: the types of this Component (`juiz pkg design check juizdesign.yaml` checks it) |
| `idl/rover.jidl` | The record and enum types (JIDL) the design document uses (`idl:`) |
| `app/python/rover.py` | The Component. Each decorated function is a type. Write the bodies (`raise NotImplementedError`) |
| `app/python/<namespace>/` | The Python types (record, enum) of `idl/rover.jidl`, generated by `juiz idl -g python` (do not edit) |
| `app/app.conf` | The configuration to start juiz with. It is also the entry of the `.juizapp` package |
| `app/juizapp.yaml` | The `.juizapp` manifest (name, version, required juiz and Python versions) |
| `pyproject.toml` | The Python packages this project uses (pyjuiz) |
| `scripts/pack.sh`, `scripts/pack.ps1` | Make `dist/rover-<version>.juizapp` |

## Requirements

- juiz <version> with Python support (`juiz --version`). `pip install juiz-cli==<version>` in the venv below is the easiest
- Python 3.10 or later

`pyjuiz` in `pyproject.toml` is pinned to the same version as juiz (`==<version>`).
When you update juiz, update `pyjuiz` to the same version.

## Set up, write, run and call

The functions in `app/python/rover.py` have the arguments and the return values written in `juizdesign.yaml`, and their bodies raise
`NotImplementedError`: calling one before you write it fails. The example calls below use the default values, or a value of the type.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -e .                # installs pyjuiz
# write the bodies of the functions (raise NotImplementedError) in app/python/rover.py, then
juiz -f app/app.conf -d         # start (keep it running)

# in another terminal
juiz process call "http://127.0.0.1:8000/process/rover_stop_command0::rover_stop_command" '{}' -p
juiz container-process call "http://127.0.0.1:8000/container_process/rover_base_drive0::rover_base_drive:rover_base0" '{"command":{"v":0.0,"w":0.0}}' -p
juiz container-process call "http://127.0.0.1:8000/container_process/rover_base_pose0::rover_base_pose:rover_base0" '{}' -p

scripts/pack.sh                 # make dist/rover-0.1.0.juizapp
juiz run dist/rover-0.1.0.juizapp
```

On Windows, create the venv with `python -m venv .venv`, activate it with `.venv\Scripts\activate`, and use `scripts\pack.ps1`.
Run `juiz` in a terminal where the venv is activated.

## Changing the design

`juiz pkg create -d` does not change a skeleton it has made. When you change `juizdesign.yaml`, change the functions in
`app/python/rover.py` and `app/app.conf` to match (`juiz pkg create -d juizdesign.yaml -b python -o <dir>` writes a new skeleton, to copy from).
When you change the `.jidl` files, generate their Python types again (the `juiz_std` types come with pyjuiz, so they are not generated):

```sh
juiz idl -g python --extern juiz_std -o app/python idl/rover.jidl
```

## Versions

The package version is `0.1.0` in both `pyproject.toml` and `app/juizapp.yaml`. When you release a new version, change both.

"""rover: a juiz component made from juizdesign.yaml (juiz pkg create -d).

Write the body of each function (replace the `raise NotImplementedError(...)` lines).
The arguments and the return values are typed by juizdesign.yaml: when you change it,
change the functions here to match.
The record and enum types are in the packages next to this file, generated from the .jidl
files of idl: (see README.md).

from juiz import juiz_container, juiz_container_process, juiz_process

from juiz_std.geometry import Pose2D
from rover.types import Velocity


@juiz_process
def rover_stop_command() -> Velocity:
    raise NotImplementedError("write the body of rover_stop_command")


class RoverBase:
    """State of the container rover_base."""

    def __init__(self, wheel_base: float, last_command: Velocity | None, pose: Pose2D):
        self.wheel_base = wheel_base
        self.last_command = last_command
        self.pose = pose


@juiz_container
def rover_base(wheel_base: float = 0.3) -> RoverBase:
    return RoverBase(wheel_base, None, Pose2D.from_value({"position": {"x": 0.0, "y": 0.0}, "theta": 0.0}))


@juiz_container_process(container_type="rover_base")
def rover_base_drive(container: RoverBase, command: Velocity) -> Pose2D:
    raise NotImplementedError("write the body of rover_base_drive")


@juiz_container_process(container_type="rover_base", readonly=True)
def rover_base_pose(container: RoverBase) -> Pose2D:
    raise NotImplementedError("write the body of rover_base_pose")

==== scripts/pack.ps1 ====
# Make dist\rover-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts\pack.ps1 [-NoBuild]   (Python has nothing to build; -NoBuild is accepted and ignored)
param([switch]$NoBuild)
$ErrorActionPreference = "Stop"
Set-Location (Join-Path $PSScriptRoot "..")
$stage = Join-Path ([System.IO.Path]::GetTempPath()) ("juiz-pack-" + [System.Guid]::NewGuid())
New-Item -ItemType Directory -Path $stage | Out-Null
try {
    Copy-Item -Recurse -Path "app\*" -Destination $stage
    Get-ChildItem -Path $stage -Recurse -Directory -Filter __pycache__ | Remove-Item -Recurse -Force
    foreach ($f in @("LICENSE-MIT", "LICENSE-APACHE")) {
        if (Test-Path $f) { Copy-Item $f $stage }
    }
    New-Item -ItemType Directory -Force -Path dist | Out-Null
    juiz pack $stage -o dist
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
} finally {
    Remove-Item -Recurse -Force $stage
}
==== scripts/pack.sh ====
#!/bin/sh
# Make dist/rover-<version>.juizapp with juiz pack (juiz docs/spec/app-package.md)
# usage: scripts/pack.sh [--no-build]   (Python has nothing to build; --no-build is accepted and ignored)
set -eu
cd "$(dirname "$0")/.."
stage=$(mktemp -d)
trap 'rm -rf "$stage"' EXIT
(cd app && tar cf - --exclude=__pycache__ .) | (cd "$stage" && tar xf -)
for f in LICENSE-MIT LICENSE-APACHE; do
  if [ -f "$f" ]; then cp "$f" "$stage/"; fi
done
mkdir -p dist
juiz pack "$stage" -o dist
